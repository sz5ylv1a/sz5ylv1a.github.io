v0.2.0 - Codename Eucalpytus - 2026/09/06

Hi! This is another major overhaul to the site's design and internal workings, which I'm gonna call "Codename Eucalpytus". The goal with this is to have a design that feels a lot more fun and alive and not as clunky whilst retaining the limitations of only using pure HTML, CSS and JavaScript instead of something more fancy like Vue or React.

This new design will feature a lot of prettier looking glass elements and graphics more reminiscent of late 2000s and early 2010s esque visuals, but with a small touch of modern stuff too; and you'll bet your ass that it'll look so pretty you wanna lick it, like Steve Jobs intended!

  • Added a new background for the website, as well as a separate background for error pages (both are provided by Perfect Hue)
  • Redesigned certain pages to better reflect this new glass-like theme
  • Hid the web button for PlayStation (check comments in source as to why)
  • Eliminated every instance of !important from the CSS code
  • Optimized footer to work better on the mobile view
  • Added current PC and Phone specs to the About page
  • Changed out the monospace font used for code and kbd to JetBrains Mono, as well as giving both elements a background
  • Added additional text to redirect pages
  • Proper fix to make the actual 404 page show up
  • Made script loading asynchronous for hopefully better load times
